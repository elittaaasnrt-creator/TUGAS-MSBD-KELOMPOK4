=== Q2 - Sebelum COMMIT ===

--- Sesi B ---

           2 | Budi    | 1000000.00
=> Sesi B belum melihat perubahan Sesi A.

=== Q3b - ROLLBACK (data direset lewat q00_setup.sql) ===

           1 | Ani     | 1000000.00

=== Q4 - SAVEPOINT ===
--- Sesi A ---
BEGIN;
UPDATE lab9.rekening SET saldo = saldo - 100000 WHERE rekening_id = 1;
UPDATE 1
SAVEPOINT sp1;
UPDATE lab9.rekening SET saldo = saldo - 200000 WHERE rekening_id = 2;
UPDATE 1
SELECT * FROM lab9.rekening ORDER BY rekening_id;
           1 | Ani     | 900000.00
           2 | Budi    | 800000.00
ROLLBACK TO SAVEPOINT sp1;
ROLLBACK
SELECT * FROM lab9.rekening ORDER BY rekening_id;
           1 | Ani     |  900000.00
           2 | Budi    | 1000000.00
COMMIT;
COMMIT
SELECT * FROM lab9.rekening ORDER BY rekening_id;
           1 | Ani     |  900000.00
           2 | Budi    | 1000000.00
=> Hanya update setelah savepoint (Budi) yang dibatalkan; update Ani bertahan.

=== Q5 - Atomicity dan consistency (CHECK saldo >= 0) ===
--- Sesi A ---
\set VERBOSITY verbose
BEGIN;
UPDATE lab9.rekening SET saldo = saldo - 100000 WHERE rekening_id = 1;
UPDATE 1
UPDATE lab9.rekening SET saldo = saldo - 99999999 WHERE rekening_id = 2;
ERROR:  23514: new row for relation "rekening" violates check constraint "rekening_saldo_check"
DETAIL:  Failing row contains (2, Budi, -98999999.00).
SELECT * FROM lab9.rekening ORDER BY rekening_id;
ERROR:  25P02: current transaction is aborted, commands ignored until end of transaction block
ROLLBACK;
ROLLBACK
SELECT * FROM lab9.rekening ORDER BY rekening_id;
           1 | Ani     |  900000.00
           2 | Budi    | 1000000.00
=> Update Ani yang valid ikut batal (atomicity); CHECK menolak saldo negatif (consistency).
